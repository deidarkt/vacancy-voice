# Редизайн v4 — критерии приёмки

Автор 04.11.2026 изменила сценарий и предоставила Figma 9QfOOmO21s4poOs5NM7iQV, узлы 4:3090, 4:3311, 4:3302, 4:3310 и скриншоты состояний. Эти требования заменяют прежние решения о монохроме, некликабельных шагах, обязательном обзоре и списке недостающих условий.

- Русский кабинет «Искра», Manrope, боковое меню и шесть быстрых действий. Только создание вакансии работает; остальные явно демонстрационные.
- Диктовка — основное действие. Весь внутренний круг запускает/останавливает запись. Текст скрыт за кнопкой «Текст ответа», доступен также без микрофона.
- После остановки: распознавание → смысловая проверка → следующий вопрос автоматически. Первоначальные четыре темы тестового сохраняются.
- Принятый сегмент зелёный; недостаточный ответ оранжевый, сопровождается подсказкой. При повторной записи предупреждение скрывается. Волна реагирует на микрофон.
- Верхние шаги позволяют вернуться к доступным ответам. Правка проверяет только изменённый ответ и сохраняет остальные. Изменение исходных данных аннулирует старый результат.
- Четвёртый принятый ответ автоматически запускает генерацию. Зелёная волна по кольцу, затем сжатие и короткий салют только после успешного ответа сервера. Уменьшенное движение учитывается.
- Результат содержит только предоставленные факты и предложенное название роли. Ни вымышленных условий, ни служебного списка «уточнить». Текст редактируется, копируется и скачивается.
- Ошибки сохраняют текст и дают повторить действие. Доступ к микрофону только по нажатию. Клавиатура, видимый фокус, мобильная ширина 375 px.

Проверки и публикация фиксируются в QA.md после выполнения, а не заранее.
