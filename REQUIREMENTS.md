## Соответствие вакансии
Спецификация до реализации; реальные состояния, пустота, ошибки, прерывания; минимум элементов с объяснимой целью; тестирование автором; компоненты/токены; прагматичное ограничение объёма. ИИ выполняет реализацию, автор принимает решения и отвечает за качество. Исследования с реальными пользователями пока не проводились.

## Неопределённости
«Резюме» трактуется как вакансия; это допущение, не подтверждение работодателя. Подлинная дата получения задания не подтверждена: известны 19:50 и обсуждение 3 ноября. Groq Free используется с ограничениями; при быстром прохождении был получен временный отказ по лимиту, повтор после паузы сработал. Приложение опубликовано на Cloudflare Workers. Репозиторий GitHub содержит документацию и архив исходников.
