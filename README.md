# Вакансия голосом

Работающий прототип голосового сбора требований к вакансии: четыре вопроса, расшифровка, проверка полноты и редактируемый черновик.

[Открыть опубликованный прототип](https://vacancy-voice.andreyeva-here.workers.dev/)

## Для проверяющего
1. Откройте приложение и нажмите «Составить вакансию».
2. Ответьте на вопрос голосом, остановите запись, проверьте текст.
3. Нажмите «Продолжить». Если модель попросит уточнение, дополните ответ голосом или текстом и нажмите «Продолжить» снова.
4. Достаточный ответ сохранится автоматически. После четырёх ответов проверьте их в обзоре и сформируйте черновик. Его можно изменить, скопировать и скачать.

Микрофон нужен только для голосового ввода. Текстовый ввод доступен как запасной способ. Записи после остановки обрабатывает Groq; API-ключ пользователю приложения не нужен. Для демонстрации используйте вымышленные рабочие ситуации, не конфиденциальные сведения.

## Запуск разработчиком
Node.js 22.13+; `npm install`, затем скопировать `.env.example` в `.dev.vars` и добавить собственный ключ Groq Free. `npm run dev` запускает локальный сервер; браузерный микрофон работает на localhost или HTTPS. `npx tsc --noEmit` проверяет типы. `npm run build` создаёт сборку. Доступ к моделям и квоты зависят от аккаунта Groq. Платный тариф не нужен и не должен включаться автоматически.

## Технологии
React, TypeScript, Vinext, Cloudflare Workers. Голос записывается MediaRecorder; Whisper large v3 turbo распознаёт после остановки, а индикатор при записи реагирует на сигнал микрофона через Web Audio. Qwen проверяет полноту и генерирует JSON, сервер валидирует результат Zod. Секрет хранится только в серверном окружении. Нет базы аудио или пользовательских аккаунтов; текстовый черновик хранится в sessionStorage вкладки.

## Ограничения
Это тестовый прототип с бесплатными квотами. При исчерпании лимита приложение показывает ошибку и сохраняет текст. Простой лимитер запросов действует в пределах экземпляра сервера и не заменяет глобальную защиту от злоупотреблений. Семантическая оценка вероятностна: в спорных случаях ответ можно уточнить и проверить заново. Перед публикацией вакансии человек проверяет текст и добавляет недостающие условия. Восстановление аудио после перезагрузки не поддерживается. Полный список фактически проведённых проверок находится в docs/QA.md.
