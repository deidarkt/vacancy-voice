# Вакансия голосом

Прототип помогает руководителю рассказать о работе: четыре вопроса, запись и расшифровка голоса, смысловая проверка ответов и редактируемый черновик вакансии. Итог проверяет человек; неизвестные условия выделены отдельно.

**Текущий статус:** прототип проверен локально, публичная ссылка на работающую версию ещё не готова. Презентация содержит скриншоты локальной версии. В репозитории доступны документация и полный архив исходников; для просмотра кода и запуска скачайте и распакуйте [vacancy-voice-source.zip](vacancy-voice-source.zip).

## Запуск исходников

В распакованном каталоге нужны Node.js 22.13+, установка зависимостей `npm install` и собственный бесплатный ключ Groq в серверном файле `.dev.vars` по примеру `.env.example`. Команда `npm run dev` запускает проект локально. Ключ в исходниках отсутствует. Микрофон браузера работает на localhost или HTTPS.

Технологии: React, TypeScript, Vinext; MediaRecorder, Groq Whisper для распознавания, текстовая модель Groq для проверки смысла и создания черновика. Свободные квоты ограничены; приложение не обещает бесперебойной работы. Подробности и фактические проверки — в документации.
