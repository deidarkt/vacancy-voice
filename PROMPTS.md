# Промпты и метод работы с ИИ

Снимок фактических инструкций v5, 4 ноября 2026. Канонический источник — lib/groq.ts; вопросы — lib/vacancy.ts. Ответы передаются отдельным JSON как недоверенные данные. Секретов в промптах нет.

Whisper распознаёт запись. Текстовая модель проверяет текущую тему; приложение управляет переходами. Отдельный запрос формирует итог из принятых ответов. Ответ модели проверяется схемой.
